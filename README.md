# Pro Player — مشغل فيديو بـ Kivy

مشغل فيديو بواجهة عربية (RTL) على شكل Lark Player، مع:

- **قوائم التشغيل** تُؤخذ تلقائياً من ألبومات الاستوديو/المعرض (أي ألبوم فيه فيديوهات، وتُتجاهل الصور).
- إنشاء قوائم تشغيل جديدة بنفسك (زر «+» أول القائمة)، وإضافة فيديوهات إليها.
- **ترتيب الفيديوهات بالسحب**: اضغط مطولاً على فيديو ← يتحدد ← (دون رفع إصبعك) حركه لمكانك، أو امسك أيقونة ≡ على اليسار.
- ترتيب تلقائي حسب: الاسم / المدة / آخر تشغيل / تاريخ الإضافة / الحجم (تصاعدي أو تنازلي) أو يدوي.
- التحديد المتعدد: تعديل الاسم، حذف من القائمة، حذف من الجهاز، إضافة لقائمة، نقل لأول/آخر القائمة.
- المشغل: ضغط مطول = سرعة ×2 حتى ترفع إصبعك (قابلة للتغيير من الإعدادات)،
  تثبيت السرعة من زر **⋮** (0.5 · 0.75 · 1 · 1.25 · 1.5 · 2 · 2.5 · 3)،
  ضغطتان لليمين/اليسار = ±10 ث (قابلة للتغيير)، سحب أفقي للتقديم، سحب عمودي: يسار سطوع / يمين صوت،
  قفل اللمس، تدوير، نسب العرض، ترجمة SRT/VTT بجوار الفيديو (عربي وإنجليزي)، تأخير الترجمة،
  تكرار / عشوائي، مؤقت نوم، تبديل المسار الصوتي، استكمال من آخر مكان، سجل المشاهدة.

## بناء الـ APK بـ GitHub

1. ارفع محتوى هذا المجلد كله إلى مستودع GitHub (الفرع `main`).
2. من تبويب **Actions** شغّل `Build APK` (أو يشتغل تلقائياً عند أي push).
3. بعد انتهاء البناء (أول مرة 30–60 دقيقة) نزّل الملف من **Artifacts → ProPlayer-apk**.
4. ثبّته على الهاتف، واسمح بالوصول للفيديوهات عند أول تشغيل.

## تجربة على الكمبيوتر

```
pip install kivy ffpyplayer
PROPLAYER_DIR=/path/to/videos python main.py
```

## الملفات

| ملف | وظيفته |
|---|---|
| `main.py` | التطبيق والصلاحيات ودورة الحياة |
| `core.py` | البيانات والترتيب والترجمة والحفظ (بدون Kivy، مُختبر) |
| `textfix.py` | تشكيل الحروف العربية وترتيب الاتجاهين (Kivy لا يفعلها وحده) |
| `bridge.py` | أندرويد: قراءة MediaStore والصور المصغرة والحذف والسطوع والصوت والتدوير |
| `engine.py` | محرك التشغيل (ffpyplayer / FFmpeg) والسرعة |
| `widgets.py` / `screens.py` / `player.py` | الواجهة |
| `tests/` | اختبارات المنطق والواجهة (بـ Kivy وهمي) |

## ملاحظات مهمة

- التشغيل برمجي (FFmpeg) وليس بالعتاد؛ فيديوهات 4K/HEVC الثقيلة قد تتقطع على الأجهزة الضعيفة.
- تغيير السرعة يعيد فتح الفيديو من نفس الموضع (أقل من ثانية غالباً).
- تعديل الاسم يغيّر الاسم داخل التطبيق فقط، ولا يلمس الملف الأصلي.
- حذف قائمة من الجهاز يخفيها داخل التطبيق فقط؛ «أنا ← إظهار القوائم المخفية» ترجعها.
- «حذف من الجهاز» يحذف الملف فعلياً (أندرويد 11+ يطلب تأكيد النظام).
